    Time Complexity

        Time complexity tells us how the running time grows as input size increases.

        O(1) – Constant Time
        int a = arr[0];

No matter how big the array is, it takes the same time.

        O(n) – Linear Time
        for(int i=0;i<n;i++){
            System.out.println(arr[i]);
        }

If the array doubles in size, the work doubles.

        O(n²)
        for(int i=0;i<n;i++){
            for(int j=0;j<n;j++){
                System.out.println(i+" "+j);
            }
        }

Nested loops.

Complexity Order

    O(1) -> O(log n) -> (n) -> O(n log n) -> O(n²) -> O(n³) -> O(2^n) -> O(n!)
